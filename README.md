📱 Gadget Heaven - Your Ultimate Tech Shop
Gadget Heaven is a modern e-commerce web application where users can explore the latest tech gadgets, manage their shopping carts, and keep track of their favorite items in a wishlist. This project focuses on a clean user interface and seamless navigation.

🚀 Features
Dynamic Category Filtering: Browse gadgets by categories such as Laptops, Phones, Smartwatches, and Accessories.

Interactive Dashboard: View and manage your selected items in the Cart and Wishlist.

Price Sorting: Sort cart items by price (High to Low) to manage your budget effectively.

Product Details: In-depth view for each gadget including specifications, pricing, and ratings.

Purchase Workflow: A simulated purchase process with a success modal and automatic cart clearing.

State Persistence: Uses Local Storage to ensure your Cart and Wishlist items remain even after a page refresh.

🛠️ Tech Stack Used
Core: React.js

Styling: Tailwind CSS

UI Library: HeroUI (formerly NextUI)

Routing: React Router DOM

Icons: React Icons
